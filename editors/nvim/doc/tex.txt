2. ACADEMIC COMMANDS & KEYMAPS                                   *tex-keymaps*

LocalLeader is `,` (comma):

  `,d`   `:Doi2Bib [doi]`  Fetch BibTeX from DOI (or `https://doi.org/...`)
                           asynchronously via `bin/doi2bib`. Inserts at cursor
                           in `.bib` buffers, appends to a single project `.bib`
                           file (copying citekey to `+`), or copies entry to `+`.
  `,c`   `:BibCite`        Fuzzy-search project `.bib` entries in `Snacks.picker`:
                           - `.tex`: inserts `\cite{key}` (or bare `key` inside
                             an open `\cite{...`)
                           - `.md`:  inserts `[@key]`
                           - `.bib`: jumps directly to the entry definition
  `,w`   `:TexWordCount`   Run `texcount -brief` asynchronously (with pure-Lua
                           fallback when `texcount` is not installed).

Standard VimTeX Chords:
  `,ll`                  Toggle continuous `latexmk` compilation
  `,lv`                  Forward-search PDF at cursor line (Skim / Okular)
  `,lc`                  Clean auxiliary build artifacts
  `,lt`                  Open VimTeX table of contents
