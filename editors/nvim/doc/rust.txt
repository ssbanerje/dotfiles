2. BUFFER COMMANDS & KEYMAPS                                    *rust-keymaps*

LocalLeader is `,` (comma):

  `,d`   `:RustDoc [crate]`  Open `https://docs.rs/<crate>` in browser (defaults
                             to identifier under cursor).
  `,e`   `:CargoExpand`      Run `cargo expand` asynchronously and display the
                             expanded Rust AST in a read-only vertical scratch
                             split.

Useful `rustaceanvim` Commands:
  `:RustLsp runnables`       Pick and run Cargo target / test
  `:RustLsp debuggables`     Pick and debug Cargo target via `nvim-dap`
  `:RustLsp explainError`    Explain Rust compiler diagnostic under cursor
  `<Leader>uh`               Toggle Rust inlay hints
